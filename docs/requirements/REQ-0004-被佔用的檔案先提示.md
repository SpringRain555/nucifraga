# REQ-0004：被其他程式佔用的檔案，開始傳之前先提示

**狀態**：已確認
**日期**：2026-10-23

## 使用者要什麼

在開始備份前，先告訴我哪些檔案被哪個程式開著、需要先關掉，讓我決定要關掉、略過還是取消。

## 驗收條件

- [ ] 只檢查這次真的要傳的檔案；沒變的檔案不檢查
- [ ] 依程式分組顯示：「Outlook（3 個檔案）」，可展開看路徑
- [ ] 三個選項：「我關好了，重新檢查」「略過這些檔案」「取消這次備份」
- [ ] 可以勾「以後都略過這些檔案」，寫進模板的 `alwaysSkipLocked`
- [ ] 檢查後才被鎖住的檔案，傳輸時略過並記 `SRC-004`，其餘照做
- [ ] CLI 模式預設略過並記 `SRC-003`；`--cancel-on-locked` 時改成取消
- [ ] nucifraga **不會**替使用者關閉任何程式

## 刻意不做

- VSS 陰影複製（需要系統管理員權限）
