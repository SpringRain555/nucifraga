# REQ-0005：不漏檔，而且備份結果可以自己驗證

**狀態**：已確認
**日期**：2026-10-23

## 使用者要什麼

以前用檔案總管複製，路徑太長的資料夾整批漏掉卻沒有人知道。現在要：該備份的一個都不漏；
漏了（例如被鎖住）一定會被列出來；備份碟上的檔案可以不靠這個程式自己驗。

## 驗收條件

- [ ] 來源資料夾路徑 ≥ 248 字元、檔案路徑 ＞ 260 字元的檔案**照樣備份成功**（端到端測試）
- [ ] 每次執行在 `_reports\<時間>\` 寫出 `report.json`、`manifest.jsonl`、`summary.txt`，**失敗與取消也寫**
- [ ] 每個沒備份到的檔案都在報告裡，附錯誤碼
- [ ] `manifest.jsonl` 的 SHA-256 能用 PowerShell 的 `Get-FileHash` 驗證相符
- [ ] 預設開啟讀回驗證：寫完之後從備份碟讀回來比對雜湊，不符就不算備份成功
- [ ] 中途強制結束後再跑一次，結果與一次跑完相同（端到端測試）

## 刻意不做

- 備份碟上的加密（建議用 BitLocker To Go，寫在 README）
