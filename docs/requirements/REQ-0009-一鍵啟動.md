# REQ-0009：不論手動測試或驗收，都用一鍵啟動

**狀態**：已實作（M1，2026-10-23）
**日期**：2026-10-23

## 使用者要什麼

不必記指令。要用、要測、要驗收，都是雙擊一個檔案。

## 驗收條件

- [x] 雙擊 `start_nucifraga.cmd`：沒建置過就自動建置，建好就開視窗；任何一步失敗都印出原因與可直接貼上的修復指令，並等按 Enter 才關
- [x] 第二次雙擊：把已開的視窗叫到前面，不開第二個
- [x] `tools\Verify.cmd`（雙擊）＝ `tools\Verify.ps1`：全部檢查，全綠才算收尾
- [x] 每個要使用者手動驗的流程，在 `tools\` 都有一個雙擊入口（例如 `tools\Try-SampleBackup.cmd`：在暫存資料夾產生假來源與假備份碟，跑一次給你看）
- [x] 啟動器不使用 PATH 上的直譯器或工具鏈，而是用已知的安裝位置或環境變數

## 刻意不做

- 安裝程式（MSI／NSIS）—— M3 之後再做；在那之前用可攜式 exe
