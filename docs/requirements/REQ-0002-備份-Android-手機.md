# REQ-0002：同一個按鈕也備份 Android 手機的照片、影片、文件

**狀態**：已確認（實作在 M2）
**日期**：2026-10-23

## 使用者要什麼

手機跟電腦在同一個 Wi-Fi 時，按「開始備份」就連手機的照片、影片與選定的文件資料夾一起備份到同一顆碟。

## 驗收條件

- [ ] 配對：桌機按「配對手機」，在手機上確認 6 位數碼，**一次完成**；之後不必再配對
- [ ] 模板可以加入「手機來源」：照片、影片（MediaStore）、使用者挑的資料夾（SAF）
- [ ] 第二次備份只傳新的或改過的檔案
- [ ] 手機上刪掉的檔案，備份碟上**移到舊版本，不刪除**
- [ ] 傳輸途中手機斷線：已傳的保留，報 `PHN-005`，下次自動補
- [ ] 手機的憑證指紋跟配對時不同：立刻停止，報 `PHN-003`
- [ ] `play` 版不宣告「所有檔案存取」權限；`full` 版可以開

## 刻意不做

- iOS
- 經由網際網路（非同一區網）備份
- 手機端當作備份目的地
