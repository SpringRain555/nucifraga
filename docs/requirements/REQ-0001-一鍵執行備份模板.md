# REQ-0001：用一份模板，一鍵執行備份

**狀態**：已確認
**日期**：2026-10-23

## 使用者要什麼

把「要備份哪些資料夾、排除什麼、備份到哪顆碟」存成一份模板。之後每次備份只要按一下，不必再設定。

## 驗收條件

- [ ] 首頁的模板卡片上直接有「開始備份」，從開啟 app 到開始備份最多 **1 次點擊**
- [ ] 可以加入現有的模板檔（含 `D:\_meta\backup-policy.json` 這種格式），也可以在 app 裡建立新模板
- [ ] 模板編輯畫面能改：名稱、來源資料夾（含別名）、排除的資料夾名稱與檔案樣式、備份碟、進階選項
- [ ] 存檔後，模板檔除了改動的值之外，**其餘位元組不變**（單元測試比對）
- [ ] `nucifraga-cli run <模板檔>` 不開視窗也能執行同一份模板，離開碼：0＝完成、1＝完成但有警告、2＝失敗、3＝已取消
- [ ] 失敗路徑：模板檔不見、格式錯誤時，首頁卡片顯示 `CFG-*` 的訊息與「重新指定」按鈕

## 刻意不做

- 排程（M3 才做；M1 先讓 CLI 可以被工作排程器呼叫）
- 一份模板多個備份碟
