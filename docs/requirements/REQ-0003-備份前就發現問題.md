# REQ-0003：開始傳之前就發現會出問題的事

**狀態**：已實作（M1，2026-10-23）
**日期**：2026-10-23

## 使用者要什麼

不要傳到一半才發現碟滿了、插錯碟、路徑太長。能事先知道的問題，在開始傳之前就說。

## 驗收條件

- [x] 備份碟沒接上 → `DST-001`，有「重試」
- [x] 插的不是這份模板上次用的碟 → `DST-003`，擋下
- [x] 空間不夠（計畫需要的大小 ＞ 剩餘空間） → `DST-002`，擋下，並寫出需要多少、剩多少
- [x] 備份碟在來源裡面（或反過來） → `CFG-005`，擋下
- [x] 路徑超過檔案總管預算 → `PATH-001`／`PATH-002`，列出數量與前 20 筆；模板設 `block` 時擋下
- [x] 來源資料夾不存在 → `SRC-001`，那個來源略過，**備份碟上它的檔案不會被當成已刪除**
- [x] FAT32 碟上超過 4 GiB 的檔案 → `DST-006`，那些檔案略過
- [x] 預檢加上掃描，在 10 萬檔的來源上（SSD）不超過 30 秒（基準測試）

## 刻意不做

- 事先估算傳輸要多久（只顯示進度）
