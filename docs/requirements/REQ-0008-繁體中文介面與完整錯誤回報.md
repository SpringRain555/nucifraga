## 使用者要什麼

介面全部是繁體中文，用詞一致、看得懂；出問題時知道發生了什麼、接下來該做什麼。

- [ ] UI 字串全部在 `ui/src/i18n/zh-TW.ts`，元件裡沒有寫死的中文或英文（`Verify.ps1` 檢查）
- [ ] 用詞與 `docs/architecture/glossary.md` 一致
- [ ] 每一個錯誤碼都有訊息與建議動作；程式的碼集合與 `error-codes.md` 相同（單元測試）
- [ ] 按鈕都是「動詞＋受詞」，沒有單獨的「確定」「OK」
- [ ] 狀態同時用圖示與文字表示，不只靠顏色
- [ ] 日期、大小、數字用台灣慣用格式
