# REQ-0006：被改掉或刪掉的檔案保留舊版本，不自動刪

**狀態**：已確認
**日期**：2026-10-23

## 使用者要什麼

來源的檔案被改壞、被誤刪時，備份碟上還找得到之前的版本。程式不要自己把舊版本刪掉。

## 驗收條件

- [ ] 來源更新或刪除一個檔案 → 舊檔出現在 `_versions\<時間>\<來源名>\<原本的相對路徑>`
- [ ] 舊版本預設永久保留；只有使用者在「舊版本」畫面按刪除才會刪
- [ ] 刪除前的確認對話框寫出完整路徑、檔案數、大小
- [ ] 一次要搬到舊版本的檔案超過門檻（預設：≥ 50 個而且 ≥ 5%）→ 停下來問（`ENG-004`）
- [ ] 所有刪除都經過 `safe_delete`；它拒絕目的地根以外、沒有標記檔、名稱格式不符的路徑（單元測試）

## 刻意不做

- 依天數自動清理（欄位保留，M3 之後再評估要不要做）
