# 錯誤碼

**這一份是錯誤碼的權威。** 程式裡的 `nucifraga_core::error::Code` 與這張表一對一；
`Verify.ps1` 的單元測試會檢查兩邊的碼集合相同，**新增一碼要兩邊一起改**。

每一碼有三樣東西：**層級**、**給使用者看的訊息**、**建議動作**。訊息與動作就是 UI 與 `summary.txt` 顯示的字。
寫法規則：

- 訊息說**發生了什麼**，用使用者的詞（「備份碟」不說「目的地 volume」）
- 建議動作說**接下來可以做什麼**，能點的按鈕就寫按鈕名稱
- 不寫「發生錯誤」「請聯絡管理員」這種沒有資訊的句子

| 層級 | 意思 |
|---|---|
| `fatal` | 這次執行不能繼續 → 結果 `Failed` |
| `error` | 這一個檔案或這一個來源沒備份到，其餘照做 |
| `warning` | 備份到了，但有需要知道的事 |
| `info` | 只記錄 |

## CFG —— 模板

| 碼 | 層級 | 訊息 | 建議動作 |
|---|---|---|---|
| `CFG-001` | fatal | 找不到模板檔，或沒有權限讀取。 | 在首頁按「重新指定」選擇模板檔的新位置。 |
| `CFG-002` | fatal | 模板檔不是有效的 JSON（第 {line} 行附近）。 | 用文字編輯器打開模板檔，修正那一行。 |
| `CFG-003` | fatal | 模板的版本（schemaVersion {found}）不是這個版本的程式看得懂的。 | 更新 nucifraga，或把 schemaVersion 改成 1。 |
| `CFG-004` | fatal | 模板裡的路徑不是完整路徑：{path} | 改成含磁碟代號的完整路徑，例如 D:\Documents。 |
| `CFG-005` | fatal | 備份碟的位置在來源資料夾裡面（或反過來），會把備份再備份一次：{path} | 把目的地改到來源以外的地方。 |
| `CFG-006` | fatal | 有兩個來源資料夾同名（{name}），在備份碟上會撞在一起。 | 在模板編輯畫面替其中一個取別名。 |
| `CFG-007` | fatal | 模板裡的值不合法：{field}（{reason}） | 在模板編輯畫面修正這個欄位。 |
| `CFG-008` | warning | 模板寫回失敗，下次執行還會再問一次同樣的事：{detail} | 確認模板檔沒有被設成唯讀。 |

## DST —— 備份碟（目的地）

| 碼 | 層級 | 訊息 | 建議動作 |
|---|---|---|---|
| `DST-001` | fatal | 找不到備份碟：{path} | 接上備份碟後按「重試」。磁碟代號變了的話，到模板編輯畫面改目的地。 |
| `DST-002` | fatal | 備份碟空間不夠：還需要 {need}，只剩 {free}。 | 換一顆較大的碟，或到「舊版本」畫面清掉不需要的舊版本。 |
| `DST-003` | fatal | 這顆碟不是這份模板上次用的備份碟。 | 確認插的是對的碟。如果是刻意換碟，到模板編輯畫面按「改用這顆碟」。 |
| `DST-004` | error | 寫入備份碟失敗：{path}（{detail}） | 檢查碟有沒有鬆脫。重跑一次只會補寫失敗的檔案。 |
| `DST-005` | error | 這個檔名在備份碟的檔案系統上不合法：{path} | 把來源的檔案改名（去掉結尾的空白或句點）。 |
| `DST-006` | error | 檔案超過 4 GB，這顆碟（FAT32）存不了：{path} | 把碟格式化成 exFAT 或 NTFS（會清空碟上資料），或把這個檔案排除。 |
| `DST-007` | fatal | 這顆碟正在被另一次備份使用。 | 等另一次備份結束；如果沒有在跑，重新插拔備份碟。 |
| `DST-008` | error | 來源裡有名稱只差大小寫的檔案，備份碟分不出來，這一個略過：{path}（與 {other} 衝突） | 把其中一個改名。 |

## SRC —— 來源

| 碼 | 層級 | 訊息 | 建議動作 |
|---|---|---|---|
| `SRC-001` | error | 找不到來源資料夾，這個來源這次整個略過（**不會**把備份碟上的檔案當成已刪除）：{path} | 確認資料夾還在、磁碟有接上。 |
| `SRC-002` | error | 沒有權限讀取：{path} | 用有權限的帳號執行，或把它排除。 |
| `SRC-003` | warning | 有 {count} 個檔案正被其他程式使用，這次略過。 | 下次備份前先關掉：{apps}。或把它們加進「永遠略過」。 |
| `SRC-004` | warning | 這個檔案在備份途中被其他程式鎖住，這次略過：{path} | 關掉使用它的程式後重跑一次。 |
| `SRC-005` | warning | 這個檔案在備份時一直在變動，這次略過：{path} | 等寫入它的程式結束後再備份。 |
| `SRC-006` | info | 略過捷徑型資料夾（junction／symlink）：{path} → {target} | 不需要處理；它指向的內容如果要備份，把目標資料夾加成來源。 |
| `SRC-007` | info | 略過只存在雲端的檔案（讀取它會觸發下載）：{path} | 要備份的話，在 OneDrive 等設定裡設成「一律保留在此裝置上」。 |

## PATH —— 路徑長度

| 碼 | 層級 | 訊息 | 建議動作 |
|---|---|---|---|
| `PATH-001` | warning（`pathPolicy: block` 時 fatal） | 有 {count} 個資料夾在備份碟上的路徑超過 {limit} 字元：備份得到，但之後用檔案總管拖回來會失敗。 | 縮短來源的資料夾名稱，或用 nucifraga 的還原功能（M3）。 |
| `PATH-002` | warning | 有 {count} 個檔案在備份碟上的路徑超過 {limit} 字元：檔案總管通常仍複製得過去，但有些壓縮程式會失敗。 | 同上。 |
| `PATH-003` | error | 名稱超過 255 字元，檔案系統存不了：{path} | 把它改短。 |

## ENG —— 引擎與目錄

| 碼 | 層級 | 訊息 | 建議動作 |
|---|---|---|---|
| `ENG-001` | warning | 備份碟上的索引損毀或版本不符，已經重建（這次會比較慢）。 | 不需要處理。原本的索引已改名保留。 |
| `ENG-002` | fatal | 程式內部錯誤：{detail} | 請把 _reports 裡的 report.json 附在 issue 回報。 |
| `ENG-003` | info | 使用者取消了這次備份。 | 已經傳完的檔案都保留；再按一次「開始備份」就會從斷掉的地方接下去。 |
| `ENG-004` | warning | 這次會把 {count} 個檔案（佔這個來源的 {ratio}）移到舊版本，數量異常地多，已經先停下來。 | 確認來源資料夾沒有被誤刪或換了位置。確定沒問題就按「確認並繼續」。 |
| `ENG-005` | warning | 這次備份沒有正常結束（程式被關閉、電腦當機或備份碟被拔掉），結束前寫好了 {count} 個檔案。 | 不需要處理：寫好的檔案都完整保留，下一次備份會從斷掉的地方接下去。 |
| `ENG-010` | fatal | 拒絕刪除：{path} 不在可以刪除的範圍內。 | 這是安全檢查擋下的，請回報 issue。 |

## PHN —— 手機（M2）

| 碼 | 層級 | 訊息 | 建議動作 |
|---|---|---|---|
| `PHN-001` | error | 在區網裡找不到已配對的手機「{device}」。 | 確認手機與電腦在同一個 Wi-Fi，並在手機上打開 nucifraga。 |
| `PHN-002` | error | 配對碼不正確或已經過期。 | 在手機上重新產生配對碼。 |
| `PHN-003` | fatal | 手機的身分與配對時不同，已經停止連線。 | 如果手機重灌過 nucifraga，先解除配對再重新配對；否則這可能不是你的手機。 |
| `PHN-004` | error | 手機沒有給讀取權限：{scope} | 在手機上的 nucifraga 打開「權限」重新授權。 |
| `PHN-005` | error | 傳輸途中手機斷線，這次沒傳完的檔案下次會補。 | 讓手機保持亮螢幕或接上電源後再試一次。 |

## APP —— 程式本身

| 碼 | 層級 | 訊息 | 建議動作 |
|---|---|---|---|
| `APP-001` | info | nucifraga 已經開著，已把那個視窗叫到前面。 | — |
| `APP-002` | fatal | 這台電腦缺少 Microsoft Edge WebView2 執行階段。 | 到微軟網站安裝「WebView2 Runtime」後再開一次。 |
| `APP-003` | warning | 設定檔損毀，已改用預設值（原檔已改名保留）。 | 在首頁重新加入模板。 |
| `APP-004` | warning | 找不到模板資料夾：{path} | 接上模板資料夾所在的碟；或在首頁按「更換模板資料夾」選一個新的。 |
| `APP-005` | warning | 這一份模板沒有搬過去，留在原處：{path}（{reason}） | 自己比對兩邊的檔案，留下要的那一份，再把它放進新的模板資料夾。 |
| `APP-006` | error | 沒辦法使用這個模板資料夾：{path}（{detail}） | 換一個資料夾，或確認這個位置可以寫入。 |
| `APP-007` | warning | 沒辦法設定排程：{detail} | 確認「工作排程器」服務在執行；還是不行的話，把這段訊息附在 issue 回報。模板裡的排程設定還在，修好後重開 nucifraga 會再試一次。 |
