# ADR-0008：清單與驗證用 SHA-256

**狀態**：已採用
**日期**：2026-10-23

## 背景

清單（`manifest.jsonl`）的目的之一是「**不靠 nucifraga 也能自己驗**」。使用者手邊一定有的工具是
PowerShell，而 `Get-FileHash` 預設就是 SHA-256。

BLAKE3 比 SHA-256 快。但我們**預期**備份的瓶頸是外接碟的讀寫，不是雜湊 ——
這是假設，不是量測結果：M1 的基準測試會量「雜湊佔傳輸時間的比例」，結果寫回這一份。

## 決定

清單、索引、讀回驗證一律用 **SHA-256**（`sha2` crate），小寫 hex。

## 考慮過但沒選的

| 方案 | 為什麼不選 |
|---|---|
| BLAKE3 | Windows 沒有內建工具可以驗；要使用者另外裝 `b3sum` |
| xxHash 等非密碼學雜湊 | 只能抓意外損壞，抓不到刻意竄改；清單的用途包括「這份備份沒被動過」 |

## 代價

- 在 CPU 沒有 SHA 指令的舊機器上，雜湊可能比碟還慢

## 什麼情況要重新考慮

- 基準測試中，同一台機器上雜湊吃掉超過 30% 的傳輸時間
